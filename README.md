GLPI IT Service Desk & Incident Management Lab

Project Overview

This project demonstrates the setup and operation of a simulated enterprise IT Service Desk using GLPI, an open-source IT Service Management (ITSM) platform.

The lab models IT support operations for Northstar Technologies, a fictional organization based in Nigeria.

The objective is to demonstrate practical IT support, incident management, user administration, ticket escalation, troubleshooting, and ITIL-aligned service management workflows.

Technologies Used

- GLPI — IT Service Management
- Docker Desktop and Docker Compose — Containerization
- MySQL-compatible database — GLPI data storage
- macOS — Lab host environment
- Microsoft 365 and Microsoft Entra ID — Simulated troubleshooting scenarios

Project Objectives

1. Deploy and configure a GLPI helpdesk environment.
2. Create organizational entities, departments, groups, and users.
3. Implement role-based access controls.
4. Simulate enterprise IT incidents and service requests.
5. Document Level 1 troubleshooting and Level 2 escalation.
6. Track ticket priorities, assignments, resolutions, and closure.
7. Configure incident categories and explore service-level management.
8. Build a documented IT support portfolio.

Incident Management Case Studies

INC-001 — Microsoft 365 Outlook Login Failure

Scenario: A Finance department employee experiences an Outlook authentication failure that prevents access to business emails.

Incident workflow:

1. Incident reported through the GLPI self-service portal.
2. Ticket reviewed and assigned to Level 1 Support.
3. Initial troubleshooting and diagnostic investigation documented.
4. Incident escalated to Level 2 Support.
5. Simulated MFA authentication issue identified.
6. Simulated MFA re-registration and access restoration documented.
7. User verification recorded.
8. Incident resolved and closed.
